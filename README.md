# users_app — приложение с пользователями

Flutter-приложение с локальной регистрацией, авторизацией и профилем пользователя.

## Возможности

- **Экран авторизации** показывается при запуске, если пользователь не вошёл в аккаунт.
- **Регистрация:** пользователь вводит имя, email, телефон, город и пароль.
  Данные сохраняются по кнопке «Сохранить».
- **Главная страница** показывает сохранённые данные в виде карточки профиля.
- **Редактирование** данных профиля.
- **Выход из аккаунта** с подтверждением, после чего открывается экран авторизации.
- Состояние входа сохраняется: после перезапуска вошедший пользователь сразу видит профиль.

## Хранение данных

Используется `shared_preferences`:

| Ключ | Что хранится |
|------|--------------|
| `user_profile` | профиль пользователя в JSON |
| `user_password_hash` | SHA-256 хэш пароля (сам пароль не сохраняется) |
| `is_logged_in` | флаг авторизации |

## Структура

```
lib/
├── main.dart                       // выбор стартового экрана, тема
├── models/user_profile.dart        // модель пользователя
├── services/auth_service.dart      // сохранение, вход, выход
├── screens/
│   ├── login_screen.dart           // экран авторизации
│   ├── profile_form_screen.dart    // ввод/редактирование данных
│   └── home_screen.dart            // главная страница с профилем
├── widgets/profile_info_tile.dart  // строка данных профиля
└── utils/validators.dart           // проверка полей форм
test/auth_service_test.dart         // тесты логики авторизации
```

## Запуск

```bash
flutter create .   # создаст папки платформ, код в lib/ не изменится
flutter pub get
flutter run
```

Тесты: `flutter test`
